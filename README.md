# Sergio Herrera | Network Admin Portfolio

Personal portfolio site in English and Spanish. ASIR student focused on Cisco networking and cybersecurity.

Built with plain HTML, CSS and JavaScript, no frameworks. Open `index.html` in a browser or host it with GitHub Pages.

## Structure

- `index.html`: page structure
- `styles.css`: styles
- `script.js`: translations, language selector, floppy disks and effects
- `downloads/`: project files offered from the floppy disks

## Editing

- Texts in both languages live in the `dictionary` object at the top of `script.js`.
- Projects are listed in the `projects` array in the same file.
